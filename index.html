一、从零安装：5 步终端配置

步骤 1：检查 Python 运行环境 耗时 10 秒

打开 Mac 终端（按 Cmd + 空格 搜索“终端”），粘贴以下命令检查环境：

python3 --version

若弹出安装开发者工具弹窗，点击“安装”即可。

步骤 2：创建独立运行沙箱（虚拟环境） 规范环境

保持系统纯净，避免库依赖冲突：

mkdir -p /Users/apple/local_indexer/local_indexer
cd /Users/apple/local_indexer/local_indexer
python3 -m venv venv
source venv/bin/activate

执行后，终端左侧出现 (venv) 即代表进入沙箱成功。

步骤 3：安装 AI 与音频底层组件 硬件加速

安装 LanceDB、PyTorch 以及音频解析库：

pip install --upgrade pip
pip install torch transformers sentencepiece lancedb soundfile torchaudio librosa pyarrow pandas
步骤 4：生成核心检索脚本 (audio_search.py) 核心算法

整段复制写入检索程序（集成 Gemma 语义理解与 Finder 直达唤起）：

cat << 'EOF' > audio_search.py
import os, subprocess, lancedb, torch, re
from transformers import AutoModel, AutoTokenizer

device = "mps" if torch.backends.mps.is_available() else "cpu"
AUDIO_DIR = "/Users/apple/Music/my music"
DB_PATH = "./lancedb_audio_store_v2"
table_name = "audio_assets_v2"
TOP_K = 6

print(f"正在加载 EmbeddingGemma-2 模型 (加速: {device})...")
model_id = "google/embeddinggemma-2"
tokenizer = AutoTokenizer.from_pretrained(model_id)
model = AutoModel.from_pretrained(model_id, trust_remote_code=True).to(device).eval()

def clean_text_for_embedding(file_path: str) -> str:
    rel_path = os.path.relpath(file_path, AUDIO_DIR)
    clean_name = re.sub(r'(\.(wav|mp3|flac|aiff|m4a|_wav|_mp3))$', '', rel_path, flags=re.IGNORECASE)
    clean_name = clean_name.replace('_', ' ').replace('-', ' ').replace('/', ' ')
    return f"音频素材 配乐 音效: {clean_name}"

def get_text_embedding(text: str) -> list[float]:
    inputs = tokenizer(text, padding=True, truncation=True, max_length=512, return_tensors="pt").to(device)
    with torch.no_grad():
        emb = model(**inputs).last_hidden_state[:, 0, :]
        emb = torch.nn.functional.normalize(emb, p=2, dim=1)
    return emb[0].cpu().tolist()

db = lancedb.connect(DB_PATH)
tables = db.table_names() if hasattr(db, "table_names") else db.list_tables()

if table_name not in tables:
    print(f"\n🚀 正在为曲库构建高精度索引: {AUDIO_DIR}")
    audio_extensions = ('.wav', '.mp3', '.flac', '.aiff', '.m4a')
    all_files = []
    for root, _, files in os.walk(AUDIO_DIR):
        for f in files:
            if f.lower().endswith(audio_extensions):
                all_files.append(os.path.join(root, f))
    
    total = len(all_files)
    print(f"📦 共发现 {total} 个音频文件，开始批量特征提取...")
    records = []
    batch_size = 128
    for i in range(0, total, batch_size):
        batch_paths = all_files[i:i+batch_size]
        batch_texts = [clean_text_for_embedding(p) for p in batch_paths]
        inputs = tokenizer(batch_texts, padding=True, truncation=True, max_length=512, return_tensors="pt").to(device)
        with torch.no_grad():
            embs = model(**inputs).last_hidden_state[:, 0, :]
            embs = torch.nn.functional.normalize(embs, p=2, dim=1).cpu().tolist()
        for p, vec in zip(batch_paths, embs):
            records.append({"id": len(records), "file_name": os.path.basename(p), "full_path": p, "vector": vec})
        print(f"进度: [{min(i+batch_size, total)}/{total}]")
    table = db.create_table(table_name, data=records)
    print(f"🎉 建立完成！共收录 {len(records)} 首素材入库。")
else:
    table = db.open_table(table_name)
    print(f"✅ 载入高精度音频库就绪，共收录 {len(table)} 首素材。")

print("\n" + "=" * 58)
print(f"🎵 音乐/音效高精度语义检索已就绪 (展示前 {TOP_K} 个推荐)")
print("• 直接输入色彩/情绪/乐器描述进行检索")
print(f"• 搜索后输入序号 [1-{TOP_K}] 自动在 Finder 中高亮选中")
print("• 输入 's' 或直接敲回车更换关键词，输入 'q' 退出程序")
print("=" * 58)

while True:
    prompt = input("\n🔍 请输入想找的音乐色彩/情绪/质感: ").strip()
    if prompt.lower() == 'q': break
    if not prompt: continue
    query_vec = get_text_embedding(f"寻找音频配乐素材: {prompt}")
    results = table.search(query_vec).limit(TOP_K).to_list()
    print(f"\n🎧 针对「{prompt}」推荐的候选结果：")
    print("-" * 58)
    for i, r in enumerate(results, 1):
        print(f" [{i}] {r['file_name']}\n     相似度距离: {r['_distance']:.4f}")
    print("-" * 58)
    while True:
        choice = input(f"👉 输入 [1-{len(results)}] 在 Finder 打开（'s' 重新搜索，'q' 退出）: ").strip().lower()
        if choice.isdigit() and 1 <= int(choice) <= len(results):
            idx = int(choice) - 1
            subprocess.run(["open", "-R", results[idx]['full_path']])
            print(f"✨ 已在 Finder 中高亮: {results[idx]['file_name']}")
        elif choice == 's' or choice == '': break
        elif choice == 'q': exit()
EOF
步骤 5：配置全局快捷单字别名 (ms / mu) 一劳永逸

绑定终端全局别名，以后开机再也不用切换目录：

echo "alias ms='cd /Users/apple/local_indexer/local_indexer && source venv/bin/activate && python audio_search.py'" >> ~/.zshrc
source ~/.zshrc

动作 指令 说明
启动搜索 ms 随时打开终端敲入，秒级唤醒本地曲库。
直达文件 1 ~ 6 在候选结果中直接输入序号，Finder 瞬间弹窗并高亮选中该文件。

退出工具 q 释放终端，退出程序。
